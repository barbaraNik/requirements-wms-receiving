## Решение — модуль «Приёмка+»

Собственная разработка. Модуль встраивается в существующий ландшафт и покрывает **ровно один процесс** — приёмку с расхождениями. 

Общая архитектура:

- **Веб-приложение** — для рабочих мест старшего смены, оператора 1С, закупщика, администратора.
- **Мобильный клиент на ТСД** — для приёмщиков на рампе.
- **Backend** — REST API, интеграционные адаптеры.
- **Хранилище фото** — локальный MinIO (S3-совместимый), on-premise.

Точки интеграции с внешним миром:
- **1С:ERP** — HTTP-сервисы 1С (JSON), двусторонняя;
- **WMS Alfa Sistem** — SOAP-сервисы, двусторонняя (запросить свободные ячейки, отправить приход в WMS);
- **ЭДО Диадок** — REST API, забрать УПД от поставщика, отправить ответ с расхождениями (для поставщиков, поддерживающих такой сценарий);
- **SMTP** и **Telegram Bot API** — уведомления;
- **Zebra ZT411** — ZPL по TCP, печать этикеток на паллеты.
